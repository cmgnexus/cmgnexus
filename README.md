# CMG Nexus

CMG Nexus is planned as an AI-led enterprise operating system for CMG, not a
generic CRM. Its core purpose is to catch missed, blocked, risky, and overdue
work across head office, warehouse, field sales, finance, purchasing,
collections, distribution, drivers, managers, documents, emails, route activity,
and B2B customers.

The current repository is the versioned home for the platform direction and
implementation plan. See the master plan for the target architecture, phased
delivery order, security gates, tenant model, and module backlog:

- [CMG Nexus Master Platform Plan](docs/cmg-nexus-master-platform-plan.md)
